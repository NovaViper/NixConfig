# Umbriel displays and scaling

Open **wdisplays** from the launcher or with **Super+Shift+D** to adjust monitors
and set fractional scaling. Framenova's built-in `eDP-1` display starts with
`vars.host.scalingFactor` from its host configuration. wdisplays has **Save to
kanshi Config** enabled: click **Apply** to save the layout, scale, mode, and
rotation. Kanshi restores the saved layout on login and monitor reconnects,
including reconnects after sleep. Profiles are saved in `~/.config/kanshi/config`,
which remains writable by wdisplays rather than being generated by Nix. After
enabling this integration, open wdisplays and click **Apply** once to save your
current layout. Other monitors use Umbriel's defaults until a profile is saved.

The top-left hot corner opens the overview after 500 ms. Change or disable it via
`hm.programs.umbriel.settings.hot_corners.top_left` (`enabled`, `delay_ms`, `action`).
**Super+Slash** shows desktop shortcuts; **Super+Ctrl+Slash** opens Noctalia's keybindings.

## Window shortcuts

The [Umbriel defaults](https://docs.noctalia.dev/umbriel/keybinds/#default-keybinds)
are configured alongside the launcher, screenshot, and utility shortcuts.

| Shortcut | Action |
| --- | --- |
| Super+arrows or H/J/K/L | Focus adjacent window |
| Super+Shift+arrows | Move column left/right or window up/down |
| Super+Tab | Cycle window focus |
| Super+Alt+Comma / Super+Period | Consume left / right (Super+Comma remains settings) |
| Super+R / Super+F | Cycle width / toggle fullscreen |
| Super+T | Toggle floating |
| Super+Ctrl+T or Super+Return | Open terminal |
| Super+P / Super+W | Toggle pin / column tabs |
| Super+Q / Super+Escape | Close window / quit with confirmation |
| Super+1–9 | Switch workspace |
| Super+Shift+1–9 or Super+Ctrl+1–9 | Move window to workspace |
| Super+Alt+Left/Right | Snap to the left/right half in stacking mode |
| Super+Alt+Up / Super+M | Toggle maximize |
| Super+Alt+Down | Clear stacking region placement |

Floating toggles and tiling actions apply only in layouts that support them.
